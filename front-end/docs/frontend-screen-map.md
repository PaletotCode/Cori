# Mapeamento de telas (Front-end)

## Psicologo (protegido)

1. Rota `/psicologo/sessao` -> `PsychologistSessionScreen`
2. Rota `/psicologo/onboarding` -> `PsychologistOnboardingScreen` (`PracticeProfileFlowScreen`)
3. Rota `/psicologo/configuracoes` -> `PsychologistPracticeSettingsScreen` (`PracticeProfileFlowScreen`)
4. Rota `/psicologo/agenda` -> `PsychologistAgendaScreen`
5. Rota `/psicologo/pacientes` -> `PsychologistPatientsScreen`
6. Rota `/psicologo/atividades` -> `PsychologistActivitiesScreen`
7. Rota `/psicologo/formularios` -> `PsychologistFormsScreen`
8. Rota `/psicologo/timeline` -> `PsychologistTimelineScreen`
9. Rota `/psicologo/triagens` -> `PsychologistTriageInvitesScreen`

## Paciente

1. Rota `/paciente/convite` -> `PatientInviteEntryScreen`
2. Rota `/paciente/sessoes` -> `PatientSessionsScreen`
3. Rota `/paciente/atividades` -> `PatientActivitiesScreen`
4. Rota `/paciente/formularios` -> `PatientFormsScreen`
5. Rota `/paciente/inbox` -> `PatientNotificationsInboxScreen`
6. Rota `/paciente/preferencias-notificacao` -> `PatientNotificationPreferencesScreen`

## Acesso

1. Rota `/psicologo/login` -> `PsychologistLoginScreen`
